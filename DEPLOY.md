# Как выложить сайт по публичной ссылке

## Вариант 1: Vercel (рекомендуется, бесплатно)

1. Установите Vercel CLI (один раз):
   ```bash
   npm i -g vercel
   ```
   Или используйте без установки:
   ```bash
   npx vercel
   ```

2. В папке проекта выполните:
   ```bash
   npm run build
   npx vercel
   ```

3. Следуйте подсказкам в терминале (логин через браузер, если нужно). После деплоя появится **публичная ссылка** вида `https://ваш-проект.vercel.app`.

4. Чтобы при каждом обновлении получать новую ссылку или привязать свой домен — зарегистрируйтесь на [vercel.com](https://vercel.com) и подключите репозиторий (Git).

---

## Вариант 2: Netlify

1. Соберите проект:
   ```bash
   npm run build
   ```

2. Зайдите на [app.netlify.com](https://app.netlify.com) → **Add new site** → **Deploy manually**.

3. Перетащите папку **`dist`** в окно браузера. Netlify выдаст публичную ссылку на сайт.

---

## Вариант 3: GitHub Pages

1. Создайте репозиторий на GitHub и загрузите код.

2. В настройках репозитория: **Settings** → **Pages** → Source: **GitHub Actions**.

3. В проекте добавьте в `.github/workflows/` workflow для сборки Vite и публикации на Pages (инструкции есть в документации GitHub Pages для Vite).

---

После деплоя любой из этих способов даст вам постоянную публичную ссылку на сайт.

---

## Поисковая выдача (SEO)

Сайт **может** попадать в поиск (Яндекс, Google): добавлены заголовки и описание страницы, обновление заголовка вкладки при переходе по разделам, файлы `robots.txt` и `sitemap.xml`.

**Ограничение:** навигация построена на хеше (`#/programs`, `#/about` и т.д.). Для поисковиков это одна страница с разным контентом. Отдельные разделы (Программы, Контакты и т.п.) не всегда индексируются как отдельные страницы в выдаче. Для полноценного SEO лучше позже перейти на обычные пути (`/programs`, `/about`) с настройкой сервера.

**Что сделать после деплоя:**

1. **Подставить свой URL** в проекте:
   - В `public/robots.txt` замените `YOUR-SITE-URL.vercel.app` на вашу реальную ссылку (например `szu.vercel.app`).
   - В `public/sitemap.xml` замените все вхождения `YOUR-SITE-URL.vercel.app` на тот же URL.
   - Пересоберите и заново задеплойте сайт.

2. **Отправить сайт в поисковики:**
   - **Яндекс:** [Вебмастер](https://webmaster.yandex.ru) → добавьте сайт → укажите URL и при необходимости загрузите sitemap.
   - **Google:** [Google Search Console](https://search.google.com/search-console) → добавьте ресурс по URL → отправьте ссылку на sitemap (например `https://ваш-сайт.vercel.app/sitemap.xml`).

После этого поисковые системы смогут находить сайт и показывать его в выдаче (с учётом ограничений хеш-навигации выше).
